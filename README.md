# Pertemuan 6: Fungsi dan Rekursif

## Deskripsi
Materi Pertemuan 6 mencakup pembuatan fungsi pengguna (User-Defined Functions), jenis-jenis argumen (positional, keyword, default, `*args`), mekanisme pass by reference vs reassignment, lambda (fungsi anonim), dan konsep fungsi rekursif untuk pemecahan masalah faktorial serta deret Fibonacci.

## Program yang Tersedia
1. `01_definisi_fungsi_dan_argumen.py`: Sintaks pembuatan fungsi, penggunaan keyword arguments, default arguments, dan variable-length arguments (`*args`).
2. `02_pass_by_reference.py`: Perbedaan perilaku saat memutasi objek terpusat vs menimpa referensi variabel di dalam scope fungsi.
3. `03_fungsi_anonim_lambda.py`: Penggunaan fungsi anonim `lambda` serta integrasinya dengan `map()` dan `filter()`.
4. `04_fungsi_rekursif_fibonacci_faktorial.py`: Implementasi fungsi rekursif untuk menghitung deret Fibonacci dan faktorial $n!$.

## Cara Menjalankan
Jalankan skrip berikut:
```bash
python 01_definisi_fungsi_dan_argumen.py
python 02_pass_by_reference.py
python 03_fungsi_anonim_lambda.py
python 04_fungsi_rekursif_fibonacci_faktorial.py
```
